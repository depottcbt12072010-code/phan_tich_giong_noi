# V1.4.0 — Progress Review & Timeline Comparison
- Added date-range review comparing tracked action items against transcript/analysis records in the selected period.
- Evidence-only report: progress, possible changes, not found in selected corpus, timeline points, and user confirmation questions.
- Does not automatically change action item status; absence of mention is not treated as non-completion.
- Sends up to 12 recent records within the chosen period (bounded text) and up to 80 tracked actions when user explicitly runs review.
- Saves up to 8 reports locally with period, counts, and output.
- JavaScript syntax checked with Node.js; not live-tested on deployed GitHub Pages/Gemini quota/mobile.
